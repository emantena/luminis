# Dados Seed

Status: proposta inicial.

## Objetivo

Definir dados mockados para desenvolvimento, testes e demonstracoes.

## Conjuntos sugeridos

- Livros populares de exemplo.
- Usuarios ficticios.
- Estantes com diferentes status.
- Resenhas com e sem spoiler.
- Feed com atividades variadas.
- Estatisticas com historico mensal.

## Regras

- Dados seed nao devem usar dados pessoais reais.
- Textos devem ser originais ou curtos.
- Capas reais so devem ser usadas se houver fonte e licenca adequadas.
