# Analytics

Status: proposta inicial.

## Objetivo

Medir uso do produto para melhorar experiencia, sem coletar conteudo sensivel desnecessario.

## Metricas candidatas

- Usuarios ativos.
- Livros adicionados.
- Leituras iniciadas.
- Leituras concluidas.
- Progresso registrado.
- Resenhas publicadas.
- Buscas sem resultado.

## Cuidados

- Nao coletar texto integral de resenhas.
- Nao coletar notas privadas.
- Respeitar configuracoes de privacidade.
- Documentar eventos antes de implementar.
