# Estrategia De Testes

Status: proposta inicial.

## Piramide

- Testes unitarios para dominio e regras.
- Testes de widget para componentes e telas.
- Testes de integracao para fluxos criticos.

## Alvos iniciais

- Status unico de leitura.
- Validacao de resenha.
- Progresso nao exceder total de paginas.
- Marcacao de spoiler.
- Filtros da estante.

## Quando testar

- Toda regra de negocio aprovada deve ter teste quando implementada.
- Bugs corrigidos devem ganhar teste de regressao quando possivel.
- Widgets compartilhados devem ter testes quando tiverem estado ou logica.
