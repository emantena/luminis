# Checklist De Regressao

## Antes de finalizar mudancas relevantes

- Projeto compila/analisar quando tooling local permitir.
- Fluxo principal alterado foi testado.
- Regras de negocio relacionadas foram conferidas.
- Documentacao foi atualizada.
- Estados vazio, carregando e erro foram considerados.
- Acessibilidade basica foi considerada.

## Produto

- Nao foi criada copia indevida de identidade visual de outro produto.
- Status de leitura continua unico.
- Spoilers continuam ocultos por padrao.
- Privacidade e bloqueio nao foram enfraquecidos.
