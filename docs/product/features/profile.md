# Feature: Perfil

## Objetivo

Apresentar a identidade literaria de um usuario.

## Conteudos possiveis

- Nome exibido.
- Foto.
- Bio.
- Estante resumida.
- Estatisticas.
- Resenhas.
- Atividades recentes.
- Seguidores e seguindo.

## Regras relacionadas

- `BR-USER-001`
- `BR-USER-002`

## Criterios iniciais

- Perfil deve respeitar configuracoes de privacidade.
- Estatisticas publicas devem ser derivadas de dados permitidos.
- Perfil deve permitir navegar para resenhas, estante e atividade.
- Perfil simples faz parte do MVP.
- A relacao social inicial sera seguir, sem exigir reciprocidade.
