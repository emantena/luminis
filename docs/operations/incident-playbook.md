# Playbook De Incidentes

Status: proposta inicial.

## Incidentes candidatos

- Falha de login.
- Perda de dados de estante.
- Feed exibindo conteudo privado.
- Spoiler exibido indevidamente.
- Erro generalizado de backend.

## Procedimento base

1. Identificar impacto.
2. Mitigar exposicao ou falha.
3. Comunicar usuarios afetados quando necessario.
4. Corrigir causa raiz.
5. Registrar aprendizado.

## Dados sensiveis

Incidentes envolvendo privacidade, bloqueio ou dados pessoais devem ter prioridade alta.
