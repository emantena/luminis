# Acessibilidade

## Requisitos iniciais

- Suporte a leitor de tela.
- Contraste adequado.
- Areas de toque de tamanho confortavel.
- Textos que respeitam configuracao de tamanho do sistema.
- Acoes com icones devem ter rotulo semantico.

## Cuidados especificos

- Barras de progresso devem ter descricao textual.
- Notas/avaliacoes nao devem depender apenas de estrelas visuais.
- Conteudo com spoiler deve ser anunciado antes de revelar.
- Capas de livros devem ter texto alternativo quando informativas.
