# Guia De Conteudo

## Tom

Claro, acolhedor e direto. O app deve conversar com leitores sem soar infantil ou burocratico.

## Idioma

Textos de interface em portugues do Brasil.

## Padroes

- Preferir frases curtas.
- Evitar termos tecnicos para usuarios finais.
- Usar verbos de acao em botoes.
- Confirmar acoes importantes com linguagem clara.

## Exemplos

Bom:
- Adicionar a estante.
- Marcar como lido.
- Atualizar progresso.
- Mostrar spoiler.

Evitar:
- Executar operacao.
- Persistir entidade.
- Sincronizacao falhou por excecao.
