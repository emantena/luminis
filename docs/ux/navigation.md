# UX: Navegacao

## Direcao inicial

App mobile-first com navegacao por abas para areas principais e pilha interna para detalhes.

## Abas candidatas

- Inicio.
- Buscar.
- Estante.
- Estatisticas.
- Perfil.

## Regras de experiencia

- Detalhe do livro deve estar acessivel a partir de busca, estante, feed e resenhas.
- Progresso de leitura deve estar a poucos toques de livros em andamento.
- Perfil de usuario deve estar acessivel por qualquer atividade social.
- Acoes principais devem permanecer simples em telas pequenas.
