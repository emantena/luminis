# Prompts De Agentes

## Agente de produto

Use `docs/product/vision.md`, `docs/product/glossary.md`, `docs/product/business-rules.md` e `docs/product/features/` para responder perguntas de comportamento do produto. Se houver lacuna, registre em `docs/product/open-questions.md`.

Ao tratar grupos de leitura, consulte `docs/product/features/reading-groups.md`.

Ao tratar recomendacoes, consulte `docs/product/features/recommendations.md`.

Para comportamento detalhado do agente de produto, consulte `docs/rag/product-agent.md`.

## Agente de arquitetura

Use `docs/architecture/`, `docs/data/` e `docs/adr/` para orientar decisoes tecnicas. Decisoes estruturais devem virar ADR.

## Agente de implementacao Flutter

Use `docs/architecture/flutter-architecture.md`, `docs/engineering/coding-style.md` e a feature documentada antes de alterar codigo.

## Agente de QA

Use `docs/product/business-rules.md`, `docs/product/features/` e `docs/engineering/testing-strategy.md` para derivar cenarios de teste.
