# Luminis

Luminis e um app Flutter para uma rede social de livros, inspirado no problema que produtos como o Skoob resolvem: organizar leituras, acompanhar progresso, descobrir livros e interagir com outros leitores.

## Documentacao

A base de conhecimento do projeto fica em [`docs/README.md`](docs/README.md). Ela foi estruturada para ser usada por pessoas e agentes em um fluxo estilo RAG:

- contexto de produto;
- regras de negocio;
- arquitetura Flutter;
- padroes de codificacao;
- guia para agentes.

Para retomar o projeto em outro computador ou chat, use [`docs/rag/session-handoff.md`](docs/rag/session-handoff.md).
