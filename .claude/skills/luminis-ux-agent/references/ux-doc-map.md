## Ao Encaminhar Para Flutter

Quando o fluxo estiver claro, informar para `luminis-flutter-agent`:

- rota;
- objetivo da tela;
- dados mockados necessarios;
- estados de tela;
- acoes primarias e secundarias;
- navegacao apos cada acao;
- regras de validacao relevantes.
